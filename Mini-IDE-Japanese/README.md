# Mini IDE - 日本語版

開発者のための高度な機能を備えたモダンで軽量なコードエディタ。

![Mini IDE](https://img.shields.io/badge/version-2.0-blue.svg)
![Python](https://img.shields.io/badge/python-3.8%2B-green.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ 特徴

### 🎯 コア機能
- **シンタックスハイライト** - Python、JavaScript、HTML、CSS、JSON、XML、Markdown、Java、C#、C/C++、Rustをサポート
- **ダーク/ライトテーマ** - 目に優しいテーマと滑らかな遷移
- **自動保存** - カスタマイズ可能な間隔で自動保存
- **フォントカスタマイズ** - プリセット（小・中・大）付きの調整可能なフォントサイズ
- **最近のファイル** - 最近開いたファイルへのクイックアクセス

### 🛠️ 高度な編集機能
- **検索と置換** - 強力な検索と置換機能
- **コード整形** - PEP8基準への自動コード整形
- **構文チェック** - リアルタイムの構文エラー検出
- **自動修正** - インテリジェントなエラー修正
- **行操作** - 行の削除、複製、上下移動
- **コメント切り替え** - クイックなコメント/コメント解除機能
- **括弧で囲む** - 様々な括弧タイプで選択範囲を囲む

### 📦 開発ツール
- **モジュールインストール** - 欠落しているPythonモジュールの自動検出とインストール
- **コード実行** - エディタから直接Pythonコードを実行
- **テストランナー** - タイムアウト設定付きの単体テスト実行
- **多言語サポート** - 様々なプログラミング言語でファイルを保存

### 🎨 ユーザーインターフェース
- **モダンなデザイン** - 滑らかなアニメーション付きのクリーンでプロフェッショナルなインターフェース
- **レスポンシブレイアウト** - 調整可能なウィンドウサイズと最大化起動
- **ステータスバー** - リアルタイムのファイル情報、カーソル位置、変更状態
- **キーボードショートカット** - 生産性向上のための包括的なキーボードショートカット
- **ツールチップ** - すべての機能のための役立つヒント

## 🚀 クイックスタート

### インストール
1. リポジトリをクローンまたはダウンロード
2. プロジェクトディレクトリに移動
3. アプリケーションを実行：
   ```bash
   python mini_ide_japanese.py
   ```

### システム要件
- **Python 3.8以上**
- **tkinter**（通常Pythonに含まれています）
- **Windows、macOS、またはLinux**

## 🎯 使用方法

### 基本操作
1. **新規ファイル作成**: 「新規」をクリックまたは `Ctrl+N` を押す
2. **既存ファイルを開く**: 「開く」をクリックまたは `Ctrl+O` を押す
3. **ファイルを保存**: 「保存」をクリックまたは `Ctrl+S` を押す
4. **コードを実行**: 「実行」をクリックまたは `F5` を押す

### 高度な機能
1. **モジュールインストール**: エディタが自動的に欠落モジュールを検出し、インストールを提案
2. **コード整形**: 「コード整形」を使用してPEP8基準を適用
3. **構文チェック**: リアルタイムの構文検証とエラーハイライト
4. **自動修正**: 一般的な問題のためのインテリジェントなエラー修正

## 🔧 カスタマイズ

### テーマ設定
- **ダークテーマ**: 高コントラストテキスト付きの黒背景
- **ライトテーマ**: クリーンで明るいインターフェース
- **カスタムカラー**: VSCode風のカラースキーム

### フォント設定
- **テキストフォント**: 8pxから32pxまで調整可能
- **ボタンフォント**: 8pxから24pxまで調整可能
- **プリセット**: 小（10px）、中（14px）、大（18px）

### 自動保存設定
- **有効/無効**: 自動保存機能の切り替え
- **間隔**: カスタム保存間隔の設定（10-300秒）
- **手動上書き**: `Ctrl+S` でいつでも保存

## 🐛 トラブルシューティング

### 一般的な問題
1. **モジュールインポートエラー**: 「モジュールインストール」機能を使用して欠落パッケージを自動インストール
2. **フォント表示問題**: 「フォントサイズ」メニューでフォント設定を調整
3. **テーマの問題**: `theme_settings.json` を削除してテーマ設定をリセット
4. **自動保存が動作しない**: 自動保存設定とファイル権限を確認

### パフォーマンスのヒント
1. **大きなファイル**: エディタは大きなファイルを効率的に処理
2. **メモリ使用量**: 自動保存は過剰なメモリ使用なしでデータ損失を防止
3. **シンタックスハイライト**: リアルタイムパフォーマンスのために最適化
