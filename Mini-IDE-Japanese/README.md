## ✨ 特徴

### 🎯 コア機能
- **シンタックスハイライト** - 15以上の言語をサポート：Python、JavaScript、HTML、CSS、JSON、XML、Markdown、Java、C#、C/C++、Rust、PHP、Ruby、Go、Swift、Kotlin
- **ダーク/ライトテーマ** - 目に優しいテーマと滑らかな遷移
- **自動保存** - カスタマイズ可能な間隔で自動保存
- **フォントカスタマイズ** - プリセット（小・中・大）付きの調整可能なフォントサイズ
- **最近のファイル** - 最近開いたファイルへのクイックアクセス
- **最適化UIレイアウト** - 文字の切り取りなし、適切なボタン表示

### 🛠️ 高度な編集機能
- **検索と置換** - 正規表現サポート付きの強力な検索と置換機能
- **コード整形** - PEP8基準への自動コード整形
- **行操作** - 行の削除、複製、上下移動
- **コメント切り替え** - クイックなコメント/コメント解除機能
- **括弧で囲む** - 様々な括弧タイプで選択範囲を囲む
- **クリップボードエラーコピー** - ワンクリックでエラーメッセージをコピー

### 🤖 インテリジェントなエラー解析と自動修正
- **スマートエラー検出** - 自動的な行番号とエラー種別の識別
- **ビジュアルエラー移動** - ハイライト付きでエラー行にジャンプ
- **自動修正機能** - 一般的な構文エラーのワンクリック修正
- **エラー提案** - 複雑な問題のための文脈認識推奨
- **多言語エラーサポート** - 構文、インデント、名前、型、属性、インポートエラー

### 📦 開発ツール
- **強化されたモジュールインストール** - 仮想環境サポート付きのコードからの依存関係自動検出
- **仮想環境管理** - 永続設定付きのカスタムvenvパス
- **コード実行** - 自動エラー解析付きでPythonコードを直接実行
- **パッケージインストール** - 仮想またはグローバル環境でモジュールをインストール
- **エラーから修正へのワークフロー** - エラー検出から解決へのシームレスな移行

### 🎨 ユーザーインターフェース
- **モダンなデザイン** - 滑らかなアニメーション付きのクリーンでプロフェッショナルなインターフェース
- **レスポンシブレイアウト** - 調整可能なウィンドウサイズと最大化起動
- **ステータスバー** - リアルタイムのファイル情報、カーソル位置、変更状態

## 🚀 インストール

### 要件
- Python 3.8以上
- Tkinter（通常Pythonに含まれている）

### クイックスタート
1. このリポジトリをクローンまたはダウンロード
2. `Mini-IDE-Japanese`ディレクトリに移動
3. アプリケーションを実行：

#### Windows（推奨）
```bash
# バッチファイルをダブルクリック（推奨）
start_ide.bat

# またはpythonw.exeで直接実行
pythonw.exe mini_ide_japanese.pyw
```

#### macOS/Linux
```bash
python mini_ide_japanese.pyw
```

### システム要件
- **Python 3.8以上**
- **tkinter**（通常Pythonに含まれています）
- **Windows、macOS、またはLinux**

## 🎯 使用方法

### 基本操作
1. **新規ファイル作成**: 「新規」をクリックまたは `Ctrl+N` を押す
2. **既存ファイルを開く**: 「開く」をクリックまたは `Ctrl+O` を押す
3. **ファイルを保存**: 「保存」をクリックまたは `Ctrl+S` を押す
4. **コードを実行**: 「実行」をクリックまたは `F5` を押す

### エラー解析と自動修正
1. **コード作成**: Pythonファイルを作成または開く
2. **コード実行**: F5を押すか実行ボタンをクリック
3. **エラー検出**: エラーが発生すると、解析ダイアログが自動的に表示
4. **自動修正**: 「🔧 自動修正」をクリックして一般的な構文エラーを修正（欠落したコロン、引用符、括弧）
5. **移動**: 「📍 行に移動」を使用してハイライト付きでエラー位置にジャンプ
6. **エラーコピー**: 「📋 コピー」を使用してエラーメッセージをクリップボードにコピー

### 仮想環境セットアップ
1. **モジュールインストーラーを開く**: 📦 インストールボタンをクリック
2. **Venv設定**: 「仮想環境を使用」を有効にし、カスタムパスを設定
3. **モジュール自動検出**: 「コードから自動検出」を選択して必要なパッケージを検出
4. **インストール**: モジュールを選択してワンクリックでインストール

### 高度な機能
1. **強化されたモジュールインストール**: 仮想環境サポート付きのコードからの依存関係自動検出
2. **コード整形**: 「コード整形」を使用してPEP8基準を適用
3. **エラーから修正へのワークフロー**: エラー検出から解決へのシームレスな移行

## 🔧 カスタマイズ

### テーマ設定
- **ダークテーマ**: 高コントラストテキスト付きの黒背景
- **ライトテーマ**: クリーンで明るいインターフェース
- **カスタムカラー**: VSCode風のカラースキーム

### フォント設定
- **テキストフォント**: 8pxから32pxまで調整可能
- **ボタンフォント**: 8pxから24pxまで調整可能
- **プリセット**: 小（10px）、中（14px）、大（18px）

### 自動保存設定
- **有効/無効**: 自動保存機能の切り替え
- **間隔**: カスタム保存間隔の設定（10-300秒）
- **手動上書き**: `Ctrl+S` でいつでも保存

## 🐛 トラブルシューティング

### 一般的な問題
1. **モジュールインポートエラー**: 「モジュールインストール」機能を使用して欠落パッケージを自動インストール
2. **フォント表示問題**: 「フォントサイズ」メニューでフォント設定を調整
3. **テーマの問題**: `theme_settings.json` を削除してテーマ設定をリセット
4. **自動保存が動作しない**: 自動保存設定とファイル権限を確認

### パフォーマンスのヒント
1. **大きなファイル**: エディタは大きなファイルを効率的に処理
2. **メモリ使用量**: 自動保存は過剰なメモリ使用なしでデータ損失を防止
3. **シンタックスハイライト**: リアルタイムパフォーマンスのために最適化
